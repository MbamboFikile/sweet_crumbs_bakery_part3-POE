## 📌 Project Overview
Sweet Crumbs Bakery is an interactive, multi-page web application designed for a boutique artisanal bakery based in Durban, South Africa. Building upon the foundational layouts developed in Parts 1 and 2, Part 3 introduces advanced client-side JavaScript functionality, interactive UI elements, enhanced search engine optimization (SEO), custom embedded map integration, and strict compliance with WCAG 2.2 accessibility standards.

The goal of this digital storefront is to showcase artisanal bakery products, offer real-time order cost estimation, present visual galleries in full-screen lightbox modal views, and streamline customer communication through validated forms and location-based mapping.
